# Бюджет

PWA для поиска по бюджету закупок. Две вкладки года (2026, 2027), в каждой пять разделов:

* **Исполнение** — закупки и договоры по каждому товару (файл «Исполнение по обеспечению…», лист «Исполнение 2026»);
* **План закупок** — плановые позиции с ценой, суммой и статусами (файл «… 2026 …», лист «2026»);
* **Бюджетная заявка** — заявка после корректировки (файл «3 - Бюджетная заявка…», лист «Отчет после корр (Analysis)»);
* **Бюджет АБП ПТД** — потребность по товарам АБП ПТД (листы «2026» и «2027» одного файла);
* **Бюджет АБП УЖЭО** — бюджет АБП УЖЭО по цехам (лист «Бюджет»).

Данные лежат в `data.json` и собираются из Excel скриптом `scripts/build_data.py`.
Как обновить данные — см. `input/README.md`.
