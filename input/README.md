# input

Сюда кладутся Excel-файлы бюджета. После загрузки сайт обновится сам (1–3 минуты).

Вид файла и год определяются по содержимому, имя не важно:

* **Исполнение** — первый лист называется «Исполнение 2026» (год из названия листа);
* **План закупок** — первый лист называется «2026» (год из названия листа);
* **Бюджетная заявка** — на первом листе в B3 «Год», в C3 год, в C4 версия (например PLAN05);
* **Бюджет АБП ПТД** — листы с названием-годом (2026, 2027), где в A2 написано «Потребность по товарам АБП на 2027г.»; в одном файле может быть сразу несколько лет;
* **Бюджет АБП УЖЭО** — лист «Бюджет» с шапкой «АБП / Код ФП / Код…». Года внутри файла нет, поэтому он берётся из имени файла: в имени должно быть, например, «2026».

Файлы за 2027 год подхватятся сами и попадут на вкладку 2027. Если файлов одного вида и года несколько, берётся самый свежий.
Можно загружать любую часть файлов: остальное останется прежним.

Какие колонки берутся (буквы Excel):

* Исполнение: BA код, BB наименование, BC ед.изм., R заказчики, FE кол-во, FF сумма, FH способ закупок, GH статус заявки, GJ статус закупки, GK дата вскрытия, GQ поставщик, GS дата договора;
* План закупок: F тип, G заказчик, M код, N наименование, P кол-во, Q цена, R сумма, U дата заявки, Y способ закупок, AW статус закупок, AX статус несостоявшейся;
* Бюджетная заявка: C АБП, M цех, N код ГПЗ, AO код товара, AR кол-во, AS цена, AV примечание;
* Бюджет АБП ПТД: статья бюджета, заказчик, цех (МВЗ), код товара и старый код, наименование, ед.изм., кол-во, цена, сумма, причина закупа, обоснование, ссылка, примечание (что есть в листе);
* Бюджет АБП УЖЭО: АБП, код ФП, код, наименование, ЕИ, наименование цеха, код МВЗ по SAP, кол-во.

Для 2027 года колонки в файлах стоят иначе, чем для 2026, поэтому колонки ищутся по названиям заголовков, а не по буквам.

Перед чтением проверяется, что в шапке стоят ожидаемые заголовки; если раскладка файла другая, он пропускается и в логе workflow написано почему.
